# Contributing to Deep Insight Agent

Thank you for your interest in Deep Insight Agent! We welcome community contributions.

[中文版](#中文版)

---

## Ways to Contribute

### 1. Submit New Analysis Methods

Each method is a standalone `.md` file — the simplest way to contribute.

See [How to Add New Methods](docs/en/how-to-add-skills.md)

### 2. Improve Existing Methods

- Fix logical gaps in methods
- Improve output structure readability
- Add de-sensitized examples

### 3. Improve Documentation

- Translate documentation
- Add usage examples
- Improve quick start guide

### 4. Report Issues

- Method selection routing inaccuracies
- Output template issues
- Quality standard gaps

---

## Submission Process

1. **Fork** this repository
2. **Create a branch**: `git checkout -b your-branch-name`
3. **Commit changes**: `git commit -m "Describe your changes"`
4. **Push branch**: `git push origin your-branch-name`
5. **Create a PR**

### Branch Naming

- New method: `method/013-your-method-name`
- Improvement: `improve/what-you-improve`
- Documentation: `docs/what-you-document`
- Fix: `fix/what-you-fix`

---

## Method Contribution Spec

### File Structure

```
insight-engine/methods/013-your-method-name.md
```

### Must Include

1. **Core positioning**: One sentence explaining "who you are"
2. **Best for**: When to use this method
3. **Output structure**: Clear output template
4. **Processing principles**: Actionable judgment criteria

### Recommended

1. **De-sensitized example**: A complete analysis example
2. **Relationship with other methods**: How to use in combination
3. **Quality standards**: How to judge if output meets standards

---

## Code of Conduct

### We Welcome

- Direct, sharp, evidence-based feedback
- Fact-based discussions
- Constructive criticism of methodology

### We Don't Welcome

- Personal attacks
- Unfounded speculation
- Filler words and empty talk

## 中文版

感谢你对 Deep Insight Agent 的关注！我们欢迎社区贡献。

### 贡献方式

1. **提交新的分析方法**：每种方法是一个独立的 `.md` 文件，详见 [如何添加新方法](docs/how-to-add-skills.md)
2. **改进现有方法**：修复逻辑漏洞、增加可读性、补充脱敏示例
3. **完善文档**：翻译文档、补充使用示例
4. **报告问题**：方法选择路由不准确、输出模板不合理

### 提交流程

1. Fork 本仓库
2. 创建分支：`git checkout -b your-branch-name`
3. 提交更改：`git commit -m "描述你的更改"`
4. 推送分支：`git push origin your-branch-name`
5. 创建 PR

### 分支命名规范

- 新方法：`method/013-your-method-name`
- 改进：`improve/what-you-improve`
- 文档：`docs/what-you-document`
- 修复：`fix/what-you-fix`

### 行为准则

- 欢迎：直接、尖锐、有证据的反馈
- 不欢迎：人身攻击、无依据的主观臆断、套话废话
