# 方法选择路由规则

## 路由决策树

```
录音输入
  ↓
内容诊断（会议类型 + 思维密度 + 用户诉求）
  ↓
方法选择
  ├─ 有矛盾/冲突 → #002 问骨
  ├─ 有假设未验证 → #007 第一性原理
  ├─ 有战略取舍 → #008 麦肯锡战略
  ├─ 有行动承诺 → #005 执行追踪
  ├─ 有合作价值 → #012 商业机会评估
  ├─ 有创意涌现 → #006 脑洞捕捉
  ├─ 有知识框架 → #004 知识结构师
  ├─ 有写作素材 → #003 选题挖掘
  ├─ 有博弈谈判 → #010 商务谈判
  ├─ 有人格关系 → #011 朋友聊天
  ├─ 需要留档 → #009 会议秘书
  └─ 高密度全谱 → #001 总秘
```

## 混合型录音处理

当录音涉及多个主题时：

1. **按时间线拆分段落**
2. **对每个段落分别诊断内容类型**
3. **为每个段落选择合适的方法**
4. **在输出中展示拆段路由表**

示例：

| 段落 | 时间 | 主题 | 密度 | 路由方法 |
|------|------|------|------|---------|
| S1 | 00:00-15:00 | 商业合作洽谈 | 🟢 高 | #012 商业机会评估 |
| S2 | 15:00-25:00 | 闲聊/关系维护 | 🔴 低 | 跳过 |
| S3 | 25:00-40:00 | 战略方向讨论 | 🟡 中 | #002 问骨 + #008 麦肯锡 |

## 配方定义

### 🔴 配方A：创始人战略深谈
**组合**：#002 → #007 → #008 → #005
**适用**：高密度战略讨论、创始人决策会议
**流程**：先用问骨刺穿表象 → 再用第一性原理审计假设 → 然后用麦肯锡分析战略选择 → 最后用执行追踪落地

### 🟡 配方B：课堂/讲授
**组合**：#003 + #004 → 可选 #001
**适用**：课堂录音、讲座、知识密集型内容
**流程**：先用选题挖掘找写作素材 → 再用知识结构师建框架 → 如需全面覆盖可加总秘

### 🟢 配方C：创意头脑风暴
**组合**：#006 → #007 → #005
**适用**：头脑风暴、产品讨论、创意会议
**流程**：先用脑洞捕捉创意 → 再用第一性原理审计假设 → 最后用执行追踪落地

### 🔵 配方D：项目复盘
**组合**：#001 + #005 → 可选 #002
**适用**：项目复盘、阶段性总结
**流程**：先用总秘全面分析 → 再用执行追踪追踪行动项 → 如有深层矛盾可加问骨

### ⚪ 配方E：快速留档
**组合**：#009 单用
**适用**：低密度会议、只需留档的场景
**流程**：直接用会议秘书生成结构化文档

### 🔶 配方F：商务谈判
**组合**：#010 单用
**适用**：商务谈判、合作协商
**流程**：直接用商务谈判方法拆解博弈

### 🟣 配方G：朋友聊天
**组合**：#011 单用
**适用**：朋友聊天、家人对话
**流程**：直接用朋友聊天方法分析关系

### 🔵 配方H：商业拓展/合作
**组合**：#012 → #005 → #003
**适用**：商业拓展、合作洽谈、资源对接
**流程**：先用商业机会评估 → 再用执行追踪落地 → 如有写作价值可加选题挖掘
