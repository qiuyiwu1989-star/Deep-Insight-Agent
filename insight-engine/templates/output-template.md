# 输出模板

每次分析前读取此文件，确保输出结构一致。

---

## 模板

```markdown
# 🔍 分析主题 · Deep Insight 分析
- **时间**: YYYY-MM-DD HH:MM-HH:MM
- **输入来源**: 录音转写 / 用户粘贴文本 / 本地文件
- **配方/方法**: 混合型拆段路由 → #XXX + #XXX + ...
- **说话人**: 张三（角色）、李四（角色）、...
- **内容摘要**: 3-5句话概括核心议题、密度分布、关键产出
---
```

## 结构要点

### 必须有（缺一不可）

| 模块 | 作用 |
|------|------|
| 背景信息 | 让读者30秒了解分析对象 |
| 拆段路由表 | 让读者了解密度分布和方法选择逻辑 |
| 每个方法的核心判断 | ≤3句话的穿透性判断 |
| 每个方法的详细分析 | 完整展开的分析内容 |
| 每个方法的证据引用 | 原文引用，标注说话人 |
| 质量自检 | 四维全部打勾 |

### 禁止

- 纯文字文档无任何图表
- 核心判断超过3句话
- 没有证据引用的分析判断
- 质量自检全部写"通过"但不说明原因
